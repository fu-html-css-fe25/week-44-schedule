# Schema, vecka 44
###### HTML & CSS, vecka 3 av 8

## Introduktion

Den här veckan tar vi layouten till nästa nivå! Med CSS Grid får du ännu fler möjligheter att strukturera upp innehållet i två dimensioner – rader och kolumner – med precision. 
Vi tittar också på hur man bygger formulär med HTML och stylar dem med CSS, så att de både känns snygga och fungerar som de ska.

## Mål för veckan:
1. Kunna använda grid för att styra layouten på en webbsida
2. Förstå hur ett formulär-element ser ut och fungerar
3. Kunna applicera styling på ett formulär-element
